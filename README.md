## Key Learning Framework

Across these notebooks, the core machine learning workflow can be summarized as:

### DATA → MODEL → LOSS → UPDATE

- **Programming and numerical tools** provide the foundation for implementing machine learning systems.
- **Linear algebra** represents data, model parameters, and transformations.
- **Probability and statistics** describe uncertainty, distributions, estimation, and model evaluation.
- **Calculus** provides gradients and optimization methods used during training.
- **Neural networks** combine these concepts into trainable models.

All notebooks in this repository were executed with their outputs saved. The accompanying videos explain the key code blocks, outputs, and theoretical concepts demonstrated in each notebook.
